# AeonixDemo

Demo project for [Aeonix Navigation Plugin](https://github.com/midgen/AeonixNavigation)

This project is saved with Unreal Engine 5.7.

It is primarily used as the target project for TeamCity jobs that test build/cook/run/test jobs for the AeonixNavigation plugin against a number of engine releases, in order to retain compatibility as much as possible. 

Currently being run against Unreal 5.5, 5.6, and 5.7 

May also be useful as reference for how to configure and use some features.
